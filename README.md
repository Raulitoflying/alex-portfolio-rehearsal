# Alex Chen Portfolio

A responsive single-page portfolio for a fictional computer science student seeking a backend engineering internship. All names, education details, and project experiences come from `student-profile.md`, which is fictional demonstration material and does not represent a real person. The contact email is the demo address included in that profile.

## Local preview

From this directory, run:

```sh
python3 -m http.server 4173
```

Then open <http://localhost:4173>.

## Files

- `index.html` — page content and structure
- `styles.css` — responsive visual styles
- `script.js` — mobile navigation and current-year footer
